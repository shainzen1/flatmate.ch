# flatmate.ch Context

## 💡 Rule of Context
If it's not in this file, the AI doesn't know it.

## 🚀 Project Goal
"Vibe-Check statt Grundriss: Wir vernetzen Menschen für ein harmonisches Zusammenleben."

Digitalize the shared flat (WG) search in the Swiss market by shifting the focus from the physical appearance of the flat to the people living in it. Personal chemistry is the primary filter, as personality fit is far more important for a successful WG than the property itself. 

## 🧠 Core Philosophy
- **Collective Matching:** We don't match individuals to rooms; we match people to groups. Every member of a WG completes the "Vibe-Check" to create a collective profile of the household.
- **Chemistry First:** Physical attributes (square meters, balcony, etc.) are secondary. The platform prioritizes social compatibility and shared living values.
- **Swiss-Centric:** Designed specifically for the nuances of the Swiss housing market (City/Canton focus).

## 🛠 Tech Stack
- **Frontend:** Next.js (React Server Components / App Router)
- **Styling:** Tailwind CSS + shadcn/ui
- **Backend/DB:** Supabase (Auth deferred for MVP)
